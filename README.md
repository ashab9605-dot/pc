# PC STUDIO — Dark Curved Poster Template Platform (HTML / CSS / JS / Python)

A complete full-stack + offline-ready dark curved-rectangle Poster Template Website (**PC STUDIO**), Live Half-Scene Customizer (5MB+ Ultra-HD PNG Export), Admin CMS with **Tap-to-Edit Live Colors/Text/Images**, and Photoshop-style **Poster Studio** with **Adobe `.PSD` import** and **Instant IndexedDB + Live Auto-Sync**.

## Two Ways To Run

### Option 1: Direct HTML Mode (Zero Setup!)
1. Extract the ZIP folder.
2. Double-click **`index.html`** (or `admin.html`, `studio.html`, `customize.html`) directly in Chrome/Edge.
3. Everything works immediately — including IndexedDB large-template storage (no 5MB localStorage failure!), Instant Save-to-Home Auto-Sync, Tap-to-Edit colors/images in Admin, 5MB+ Ultra-HD PNG Download, and offline `.PSD` file import!

### Option 2: Full-Stack Python Flask Server Mode
1. **Windows**: Double-click **`run_server.bat`**
2. **Mac/Linux**: Run `bash run_server.sh`
3. Open `http://127.0.0.1:5000/` in your browser.
